# Aydina & Fadzlan — wedding invite

Static site served by Netlify (aydina-fadzlan.com).

- `index.html` — the whole invite (settings at the top of the script: names, schedule, contacts, music, Supabase keys)
- `envelope.mp4` / `envelope.jpg` — 3D envelope opening and its first frame
- `music.mp3` — background music
- `img/`, `fonts/` — Monet painting backgrounds and self-hosted fonts
- `_redirects` — makes `aydina-fadzlan.com/CODE` open the invite for that guest
